# 镜头选择与物理消歧

当用户只给情绪/叙事意图，或点名了互相矛盾的镜头动作时读取。

## 先按镜头任务选机制

| 镜头任务 | 优先机制 | 选择理由 |
|---|---|---|
| 靠近人物情绪或关键细节 | 缓慢推进 | 让主体自然增大，同时保留真实透视变化 |
| 从人物扩展到世界 | 缓慢拉远、摇臂升起或航拍揭示 | 逐步增加环境信息 |
| 把注意力从一个对象转到另一个对象 | 拉焦、摇镜或受控横移 | 取决于两个对象是深度关系还是横向关系 |
| 建立空间层次 | 横移、弧线绕行 | 通过前景视差和侧面信息证明三维空间 |
| 表达人物关系 | 过肩构图、侧向跟拍、半环绕 | 把双方距离和视线放入同一空间关系 |
| 跟随行动 | 倒退跟拍、尾随、平行侧跟、第一人称 | 用稳定的相对距离和方向维持连续性 |
| 心理不安或空间失真 | 眩晕变焦、轻微手持、倾斜地平线 | 分别作用于透视、稳定性和水平基准 |
| 揭示、入场或转场 | 遮挡揭示、穿越入口、甩镜 | 利用真实遮挡或运动模糊连接状态 |
| 宏大规模和地理关系 | 航拍掠过、抬升揭示、大半径环绕、正俯拍 | 增加可见范围和空间关系 |
| 细节或造型展示 | 上下摇、固定变焦、微距深入 | 按纵向、景别或尺度关系引导注意力 |

一个任务可能有多个合理机制。根据参考图现有空间信息选择最省补全、最容易说明落点的方案。

## 六类机制

### 1. 机位平移

推进、拉远、横移、升降、轨道跟拍、绕行、航拍。相机位置改变，因此透视和视差应变化。

### 2. 机位旋转

水平摇镜、垂直摇镜、滚转或倾斜。相机位置固定，只改变朝向或地平线。

### 3. 光学变化

固定机位变焦、冲击变焦。相机位置固定，主要改变视野和主体画面尺度，不产生真实平移透视。

### 4. 焦点变化

虚焦到清晰、前后景拉焦。构图可以固定，变化的是清晰平面。

### 5. 相对跟随

相机与运动主体保持指定速度、距离和方位。它是对机位平移的约束，不等于只写“跟着人物”。

### 6. 遮挡或空间转场

从遮挡物后揭示、穿过门窗、甩镜切换、跨尺度深入。关键是路径上的遮挡、入口、落点和中间几何状态。

## 高频混淆

| 容易混淆 | 精确区分 |
|---|---|
| 推进 vs 变焦拉近 | 推进改变相机位置和透视；变焦保持机位，只改变视野 |
| 垂直摇镜 vs 机位升降 | 摇镜只转动朝向；升降让整台相机上移或下移 |
| 主体旋转 vs 相机环绕 | 前者背景相对机位基本不变；后者产生连续视差并揭示主体侧后方 |
| 拉焦 vs 推进 | 拉焦改变清晰对象；推进改变距离、景别和透视 |
| 手持 vs 随机抖动 | 手持是小幅、低频、可读的自然漂移；随机大抖会破坏主体 |
| 遮挡揭示 vs 直接出现 | 揭示必须让前景遮挡先占据画面，再因相机运动退出 |
| 穿越 vs 硬切 | 穿越要有连续入口和两侧空间；硬切只需要视觉匹配 |

## 参考图兼容性检查

在写运动前检查：

1. 路径是否在画面中有空间？
2. 推进的目标是否清晰可见，拉远的环境是否有连续扩展依据？
3. 横移或绕行是否有前景、中景、背景深度？
4. 穿越是否有足够大的入口，遮挡揭示是否有合适前景？
5. 拉焦的两个对象是否有足够的纵深距离？
6. 终点所需的信息是否由参考图或终帧提供？

若两个以上答案是否定，优先重做参考图或拆镜头。

## 风险分级与关键帧

- 低风险：单轴慢推、拉远、单方向摇镜、简单固定变焦。通常一张参考图即可。
- 中风险：环绕、快速跟拍、明显拉焦、航拍揭示、遮挡揭示。根据终点是否可推断决定首尾帧。
- 高风险：穿门跨空间、甩镜切换主体、宏观到微观、宇宙到街道、多段连续转场。默认首尾帧；路径跨度大时增加中间帧。

时长只作初始测试：慢镜头 5-8 秒，快镜头 3-5 秒。若运动距离与时长不匹配，先调整距离或拆镜头，不要只写“更快”。
