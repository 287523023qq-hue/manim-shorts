# 镜头运动合同语法

仅在需要编写、改写或审查具体提示词时读取。

## 核心公式

```text
[镜头指令：起点 + 机制 + 路径/方向 + 速度曲线 + 终点]
+ [主体：动作 + 画面位置/尺度/形态/清晰度固定项]
+ [环境：前景/视差/焦点/背景与光线连续]
+ [针对性约束：1-3 条]
```

最终输出应是一段自然语言，不必把槽位标签写给生成系统。槽位用于内部检查。

## 七个槽位

| 槽位 | 要回答的问题 | 合格示例 | 不合格示例 |
|---|---|---|---|
| 起点 | 从什么景别、角度和主体位置开始？ | 从人物腰部中景开始 | 从一个电影画面开始 |
| 机制 | 是机位平移、旋转、变焦、拉焦还是相对跟随？ | 相机沿光轴向前平移 | 镜头靠近一点 |
| 路径 | 朝哪里、走直线还是弧线、移动多少？ | 沿人物左侧做约 120 度弧线绕行 | 环绕人物 |
| 速度 | 匀速、缓入缓出、冲入后制动，幅度多大？ | 6 秒内缓慢推进并在终点平稳停住 | 慢慢地、有感觉地移动 |
| 主体锁定 | 哪些主体属性不能漂？ | 人物保持居中，脸部尺度平滑增大，动作轻微 | 人物不要崩 |
| 环境响应 | 如何证明运动真实发生？ | 近处雨伞快速掠过，远处霓虹缓慢位移，背景连续 | 环境很有层次 |
| 落点 | 最终停在哪里、什么清晰？ | 停在眼部近景，双眼清晰 | 最后很好看 |

## 输入模式

### 有参考图

参考图已承担人物外观、服装、色彩和场景。提示词尽量只写：

```text
相机从当前中景沿光轴缓慢平滑推进，6 秒内收至人物面部近景；人物保持居中并轻微呼吸，头部姿态和面部特征稳定；前景雨滴产生轻微视差，背景霓虹连续并逐渐虚化；最终停在清晰的双眼上。
```

不要复述参考图里已经清楚的发型、服装和布景，除非某个属性在运动中必须锁定。

### 无参考图

需要补齐主体与环境，但镜头指令仍放在最前：

```text
相机从低机位全景开始，沿直线缓慢升至人物眼平并在 6 秒末稳定停住；一名穿湿透红色风衣的年轻摄影师站在雨夜巷口，保持居中，只做轻微呼吸；近处透明雨棚从画面上沿退出，远处蓝绿色招牌和暖色路灯保持空间连续，水面倒影产生自然视差。
```

## 典型编译示例

### 模糊意图：更紧张

若紧张来自人物心理压力，可选眩晕变焦：

```text
相机沿光轴缓慢后移，同时同步放大焦距，使人物头肩尺度和画面中心位置保持不变；人物僵直注视镜头，面部形态稳定；走廊背景在 5 秒内被明显拉长，墙线持续向后延伸，光线和场景保持连续；终点仍停在人物清晰的双眼上。
```

### 模糊意图：展示环境很大

选择拉远或升起揭示，不能只写“史诗感”：

```text
相机从人物背后的肩部中景开始，沿直线平滑后退并轻微升高，7 秒内展开为高位大全景；人物保持画面下方中央、朝向不变；两侧山壁逐步进入画面，前景碎石快速退去，远处山谷和道路连续显露；最终停稳，让人物在巨大环境中保持可辨识。
```

### 模糊意图：把注意力从人转到物

选择拉焦，不移动相机：

```text
机位和构图完全固定，焦点在 3 秒内从前景人物的眼睛平滑转移到后景桌面的钥匙；人物逐渐虚化，钥匙最终锐利清晰；两者位置、尺度、光线和背景保持不变，焦点落在钥匙齿纹上并停住。
```

### 参考图不支持运动

若用户要求“穿过门进入房间”，但画面中的门被主体挡住或开口过小，不要硬写。说明需要重做起始图：门洞完整可见、路径无障碍，终点图保持门后空间方向一致。

## 写作规则

- 使用可见动词：推进、后退、横移、上升、俯冲、旋转、转焦、揭示、停住。
- 使用几何关系：沿光轴、水平向左、垂直上升、120 度弧线、与人物等速、保持 2 米距离。
- 使用时间关系：前 1 秒静止、随后匀速、末 0.5 秒减速停住；只有确有需要才写精确分段。
- 优先写正向结果：“背景连续、主体居中、机位稳定”；只保留少量有诊断价值的禁止项。
- 不编造焦段、帧率、快门或设备型号。用户给出或镜头任务明确需要时再写。
- 输出语言跟随用户。需要英文时翻译运动关系，不只翻译镜头名称。

## 交付前检查

- [ ] 镜头指令在最前
- [ ] 起点和终点都可画出来
- [ ] 只有一个主机制，或是一个有定义的协同机制
- [ ] 写清至少一个变化项和必要固定项
- [ ] 路径、方向和速度无歧义
- [ ] 主体动作不会与运镜争抢过多变化
- [ ] 环境提供视差、遮挡或连续性证据
- [ ] 每条约束都能从生成结果直接检查
- [ ] 高风险路径已评估关键帧
