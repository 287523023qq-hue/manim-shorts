# 失败诊断与改写

用户提供失败结果、失败描述或要求优化旧提示词时读取。一次只修改最可能的 1-2 个槽位，保留其余变量，才能判断修改是否有效。

| 可见失败 | 最可能缺失/冲突 | 优先修改 |
|---|---|---|
| 镜头几乎没动 | 机制、距离或视差不明确 | 加入物理路径和前景响应，不只加强“明显” |
| 推进看成画面放大 | 未区分机位移动和变焦 | 写“相机沿光轴向前平移，焦距保持不变，透视自然变化” |
| 人物漂出画面 | 缺少主体屏幕位置约束 | 指定居中/三分位、相对距离或跟随速度 |
| 人脸或物体变形 | 运镜与主体动作过多、速度过快 | 降低主体动作和运动强度，锁定形态与朝向 |
| 背景突然换场 | 环境连续性和参考信息不足 | 固定场景、光向和空间结构；必要时补终帧 |
| 横移像平面贴图 | 缺少深度层和视差 | 增加近前景、中景主体、远背景的差速关系 |
| 环绕变成主体自转 | 未声明谁绕谁 | 写“主体静止，相机保持半径沿弧线绕行，背景产生连续视差” |
| 摇镜变成机位升降 | 固定项不清 | 写“机位位置固定，仅相机朝向向上/向下旋转” |
| 拉焦不明显 | 深度差不足或未写焦点两端 | 指定前后对象和最终清晰落点；重做有纵深的参考图 |
| 快速镜头一片模糊 | 速度无制动、主体无落点 | 缩短路径或降低速度，末段减速并停在清晰主体上 |
| 穿越入口失败 | 入口尺寸、方向或两侧空间不连续 | 重做首尾帧并对齐入口轴线，必要时补门内中间帧 |
| 尺度穿越跳步 | 相邻状态跨度太大 | 增加中间尺度关键帧，不继续堆形容词 |
| 终点正确但过程错误 | 只约束首尾，没有路径 | 补一张发生关键空间变化的中间帧 |
| 画质好但逻辑错误 | 评价标准混淆 | 单独检查路径、遮挡、方向和因果，不以清晰度判定运动成功 |

## 修改顺序

1. 先查物理矛盾：谁在动、沿什么路径、什么固定。
2. 再查起点和落点是否明确。
3. 再查主体与环境约束。
4. 最后才调整速度、时长和措辞强度。
5. 若失败来自缺失空间信息，停止改词，改参考帧或拆镜头。

## 复测记录

建议内部记录：原提示词、唯一修改项、预期改善、实际结果。连续两次修改同一槽位仍无改善时，换运动方案或重做参考图，不无限重试。
