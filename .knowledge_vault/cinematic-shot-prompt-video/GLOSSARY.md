# 术语词典

| 术语 | 在本 Skill 中的含义 | 容易混淆的概念 |
|---|---|---|
| 镜头任务 | 该镜头要完成的叙事或注意力目标 | 不是风格标签 |
| 运动机制 | 平移、旋转、光学变化、焦点变化、跟随或路径转场 | 不把所有变化都叫“运镜” |
| 固定项 | 运动中必须保持不变的可见属性 | 应按镜头选择，不是全部锁死 |
| 变化项 | 相机位置、朝向、焦距、焦点或主体相对关系中被允许改变的变量 | 一个镜头通常只设一个主变化机制 |
| 起始状态 | 开始时的景别、角度、主体位置和焦点 | 不只是一张参考图文件 |
| 运动路径 | 相机从起点到终点的方向、轨迹和相对几何关系 | “推进”“跟拍”等名称仍需展开 |
| 速度曲线 | 匀速、缓入缓出、快速冲入后稳定等时间变化 | 不只是“快/慢”二选一 |
| 主体锁定 | 需要保持的画面位置、尺度、形态、朝向或清晰度 | 不等于主体必须完全不动 |
| 环境响应 | 视差、遮挡揭示、背景连续、光线连续和焦点变化 | 不是重复写场景美术描述 |
| 落点 | 运镜最终停在什么景别、对象、角度和焦点上 | 必须是可观察的终帧状态 |
| 关键帧 | 路径上必须经过的参考状态 | 高风险镜头才需要增加，不宜机械滥用 |
| 运动合同 | 由起点、机制、路径、速度、固定项、环境响应和落点组成的可验证描述 | 是本 Skill 的迁移推断，不是视频原词 |
