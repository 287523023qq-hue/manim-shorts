# Glossary Candidates

提取方式：子代理因额度限制中断，以下由主流程回看材料并结合摄影学常用定义整理；视频未严格定义的条目标为“迁移解释”。

| 术语 | 操作定义 | 关键区分 | 来源位置 |
|---|---|---|---|
| 镜头指令 | 相机、镜头光学或焦点在时间中的明确变化 | 不等于“电影感”效果词 | 13:20-13:36 |
| 机位平移 | 整台相机在三维空间移动 | 会产生透视和视差变化；不同于 zoom | 00:06-00:31; 04:44-05:14 |
| 摇镜 | 机位固定，相机朝向水平或垂直旋转 | 不改变相机位置；不同于升降 | 04:13-04:44 |
| 光学变焦 | 机位固定，只改变视野范围和主体画面尺度 | 不产生真实机位移动的透视变化 | 08:03-08:36 |
| 眩晕变焦 | 机位移动与反向变焦同步，使主体尺度近似不变、背景透视变化 | 不是普通推进，也不是单独 zoom | 00:59-01:19 |
| 拉焦 | 机位和构图可保持稳定，清晰平面从一个对象转到另一个对象 | 不改变主体位置或景别 | 03:27-04:01 |
| 主体锁定 | 指定主体在运镜中保持的画面位置、尺度、形态或清晰度 | 只锁必要变量，不等于主体完全静止 | 多处示例 |
| 视差 | 不同深度物体因相机位移呈现不同屏幕速度 | 是横移、环绕具有空间感的可见证据 | 04:44-05:00; 12:04-12:11 |
| 落点 | 运镜结束时的主体、景别、角度、焦点和稳定状态 | 不只是“结束”，而是可检查的终帧 | 07:38-07:56; 10:45-11:03 |
| 关键帧 | 明确路径中一个空间或尺度状态的参考图 | 首尾帧是最少集合，中间帧用于限制复杂过渡 | 14:20-16:06 |
| 高风险镜头 | 穿越、转场、极端尺度变化或空间跨度大、模型需大量补全的镜头 | 风险来自中间几何未知，不等同于视觉华丽 | 14:20-14:29 |
